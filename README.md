# 🤖 Getoken - نظام الأتمتة الذكي

## 📋 نظرة عامة

**Getoken** هو نظام أتمتة متكامل لإنشاء حسابات فيسبوك واقعية (بأسماء جزائرية) وتنفيذ مهام تقييم ذكية. مصمم ليعمل بتكلفة **0 دولار** على منصة **Railway**.

## 🎯 الهدف

- إنشاء حسابات فيسبوك واقعية بأسماء جزائرية
- نضج الحسابات بشكل طبيعي لتجنب الكشف
- تنفيذ مهام تقييم (نجوم + تعليقات) على البروفايلات والمتاجر
- لوحة تحكم ويب سهلة الاستخدام
- نظام حماية مضاد للكشف

## 🚀 التشغيل المحلي

### المتطلبات
- Python 3.9+
- PostgreSQL (أو استخدام Railway)

### التثبيت

```bash
# استنساخ المشروع
git clone <repo-url>
cd Getoken

# إنشاء بيئة افتراضية
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# تثبيت المكتبات
pip install -r requirements.txt

# نسخ ملف البيئة
cp .env.example .env

# تعديل .env حسب إعداداتك

# تشغيل قاعدة البيانات
# (أو استخدم Railway)

# تشغيل البوت
python -m bot.main

# تشغيل واجهة الويب (في terminal آخر)
python web/app.py
```

## 🌐 التشغيل على Railway

1. أنشئ حساب على [Railway](https://railway.app)
2. اربط المشروع بـ GitHub
3. أنشئ خدمة جديدة من هذا المستودع
4. أضف PostgreSQL كقاعدة بيانات
5. عدّل متغيرات البيئة في Railway
6. انشر المشروع!

### Procfile
```
web: gunicorn web.app:app
worker: python -m bot.main
```

## ⚙️ الإعدادات

### إعدادات البوت (في .env)

| المتغير | الوصف | القيمة الافتراضية |
|---------|-------|-------------------|
| `BOT_ENABLED` | تفعيل/تعطيل البوت | `true` |
| `BOT_INTERVAL_HOURS` | فترة التحقق (ساعات) | `24` |
| `MAX_ACCOUNTS_PER_DAY` | حد الحسابات يومياً | `1` |
| `ACCOUNT_MATURITY_DAYS` | فترة نضج الحساب | `14` |
| `MAX_RATINGS_PER_ACCOUNT` | حد التقييمات للحساب | `15` |
| `MIN_DELAY_SECONDS` | أقل تأخير بين الإجراءات | `30` |
| `MAX_DELAY_SECONDS` | أكثر تأخير بين الإجراءات | `120` |

## 📊 قاعدة البيانات

### النماذج الرئيسية

1. **Account** - حسابات فيسبوك
   - البريد الإلكتروني، كلمة المرور
   - الاسم، المدينة، الصورة
   - الحالة (creating/maturing/ready/active/banned)
   - الإحصائيات

2. **Task** - المهام
   - رابط الهدف
   - نوع التقييم
   - التقدم والحالة

3. **Rating** - التقييمات الفردية
   - النجوم والتعليق
   - الحالة (success/failed)

4. **ActivityLog** - سجل النشاط
5. **Proxy** - إدارة الـ Proxies
